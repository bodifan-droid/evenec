# ADR-0002 — CC BY 4.0 License

**Status:** Accepted

**Date:** 2026-08-26

---

## Context

Evenec aims to become an open knowledge project.

The content should remain freely accessible while preserving attribution.

## Decision

Books are published under:

**Creative Commons Attribution 4.0 International**

## Consequences

Readers may:

- share
- redistribute
- adapt

They must provide attribution.

This decision supports long-term educational growth.
