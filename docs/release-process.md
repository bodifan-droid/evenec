# Evenec Release Process

Every release follows the same workflow.

## Content

- Write the chapter.
- Save all files.
- Render with Quarto.
- Review HTML.
- Review PDF.

## Git

```powershell
git status
git add .
git commit -m "Describe the completed work"
git push
```

## Release Checklist

- Content complete
- No broken tables
- Navigation works
- PDF opens
- HTML works
- GitHub updated
