18 Sprint 2 — Thinking in DAX

18.1 Measures • CALCULATE • FILTER • RELATED • ALL

Welcome to Sprint 2.

This chapter teaches the biggest mindset shift in Power BI.

DAX isn’t Excel.

DAX thinks in context.

We’ll continue using the Evenec Retail Playground.

Main files:

  • customers.csv
  • orders.csv
  • products.csv
  • payments.csv

19 What Makes DAX Different?

Excel asks.

“What’s in this cell?”

DAX asks.

“Which rows are currently visible?”

Memory Hook.

Excel thinks in cells.

DAX thinks in context.

20 Understanding Context

Imagine.

Your report is filtered to:

  • London
  • January

When you calculate Revenue,

DAX automatically uses only those rows.

That’s called Filter Context.

21 Two Types of Context

Context Meaning
Row Context Current row
Filter Context Current visible data

Interview Tip.

Being able to explain these two concepts is more valuable than memorising dozens of functions.

22 Interview Question 4

Explain Filter Context.

Good Answer (B2).

Filter Context is the set of filters currently affecting a calculation, such as city, category or date.

Simple.

Professional.

Correct.

23 Your First Measure

Open.

Model View.

Create.

New Measure.

Write.

Total Revenue =
SUM(Orders[amount])

Why a Measure?

Because it updates automatically whenever filters change.

Memory Hook.

Measures breathe.

Columns stay fixed.

24 Calculated Column vs Measure

Calculated Column Measure
Stored Calculated
Every row Entire context
Static Dynamic

Business Example.

Customer Tier.

→ Column.

Total Revenue.

→ Measure.

25 Interview Question 5

Why use a Measure?

Model Answer.

Measures recalculate automatically whenever report filters change.

Recruiters love this answer.

26 COUNT vs COUNTROWS

Two similar functions.

Different purpose.

Total Orders =
COUNTROWS(Orders)

Why COUNTROWS?

Because you’re counting records.

Not values.

Memory Hook.

Rows.

Not cells.

27 AVERAGE

Create.

Average Order =
AVERAGE(Orders[amount])

Now compare.

  • Revenue
  • Orders
  • Average Order

You’re building executive KPIs.

28 CALCULATE

This is the heart of DAX.

Formula.

London Revenue =
CALCULATE(
    [Total Revenue],
    Customers[city]="London"
)

Notice.

You’re changing the context.

Memory Hook.

CALCULATE changes reality.

29 Why CALCULATE Matters

Without it.

Current filters remain.

With it.

You create new business questions.

Examples.

  • London only
  • Electronics only
  • Last year only

This is why CALCULATE appears in almost every real project.

30 FILTER

Sometimes conditions become more complex.

Example.

Large Orders =
CALCULATE(
    [Total Revenue],
    FILTER(
        Orders,
        Orders[amount]>200
    )
)

Business Meaning.

Revenue from high-value purchases.

Interview English.

FILTER allows me to create more specific business conditions.

31 RELATED

Power BI already knows relationships.

Now use them.

Example.

Customer City =
RELATED(Customers[city])

Think back.

SQL.

JOIN

Excel.

XLOOKUP

Power BI.

RELATED

Same business goal.

Different tool.

32 RELATEDTABLE

Imagine.

You’re inside Customers.

You want.

All related orders.

Use.

RELATEDTABLE(Orders)

Memory Hook.

RELATED looks outward.

RELATEDTABLE looks inward.

33 ALL

One of the most important interview functions.

Example.

Revenue % =
DIVIDE(
    [Total Revenue],
    CALCULATE(
        [Total Revenue],
        ALL(Customers)
    )
)

Business Meaning.

Current revenue.

Compared to total company revenue.

Exactly what executives ask.

34 DIVIDE

Don’t write.

A/B

Use.

DIVIDE(A,B)

Why?

Safer.

No divide-by-zero errors.

Interview Tip.

Using DIVIDE instead of / shows professional habits.

35 Time Intelligence Preview

Next sprint goes deeper.

For now.

Create.

Current Year Revenue =
TOTALYTD(
    [Total Revenue],
    Orders[order_date]
)

Notice.

Power BI understands dates differently from Excel.

36 Mini Business Case

The Sales Director asks.

How much revenue came from London?

Use.

CALCULATE.

Then answer.

London generated £X in revenue.

Business language matters.

37 Mini Business Case

Question.

What percentage of total revenue comes from Electronics?

Hint.

Use.

  • CALCULATE
  • ALL
  • DIVIDE

Think before writing.

38 Common DAX Mistakes

Avoid.

❌ Using calculated columns instead of measures.

❌ Forgetting relationships.

❌ Ignoring Filter Context.

❌ Dividing manually.

Memory Hook.

Think.

Context.

Then formula.

39 DAX Cheat Sheet

Function Purpose
SUM Add values
COUNTROWS Count records
AVERAGE Average
CALCULATE Change context
FILTER Complex conditions
RELATED Bring related value
RELATEDTABLE Return related rows
ALL Remove filters
DIVIDE Safe division

Keep this table nearby.
