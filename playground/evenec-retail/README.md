# Evenec Retail Playground

> Practice every SQL exercise from the **Data Analyst Interview Bible (UK 2026)** using a realistic business dataset.

## What's Included

- SQLite Database (`evenec_retail.db`)
- SQL Schema (`evenec_retail_schema.sql`)
- Seed Data (`evenec_retail_seed.sql`)
- CSV Files for Excel & Power BI
- Companion Practice Guide

## Dataset Overview

| Table       | Records |
| ----------- | ------: |
| customers   |     750 |
| orders      |   1,800 |
| order_items |  ~4,500 |
| products    |     120 |
| payments    |   1,800 |
| employees   |      40 |

## Quick Start

1. Open `evenec_retail.db` in VS Code.
2. Install the SQLite extension (if needed).
3. Run the queries from SQL Sprint 1–4.
4. Explain every solution aloud in English.
