# STAR Framework

Category: Interview Method

Difficulty: Essential

---

## Purpose

Answer behavioural questions with clear structure.

## Structure

| Step | Meaning   |
| ---- | --------- |
| S    | Situation |
| T    | Task      |
| A    | Action    |
| R    | Result    |

## Memory Hook

STAR

Situation → Task → Action → Result

## Example

Situation

Workflow delays appeared.

Task

Reduce processing time.

Action

Reviewed communication and reorganised the workflow.

Result

The process became smoother.

## Common Mistake

Spending too much time describing the situation instead of the action.
